## 写作规则

### 语气与风格
- 语气：犀利+热血混合体。叙述时冷静精准，转折时情绪爆裂
- 节奏：快节奏信息密集，短句连击+数据轰炸，像机关枪扫射
- 情感倾向：理情结合，以理铺路、以情收刀。80%篇幅理性叙事，最后20%情绪升华
- 人称：第三人称叙事为主，偶尔切第一人称制造临场感

### 用词习惯
- 高频词：逆袭、崛起、碾压、硬刚、暴击、梭哈、降维打击、清场级、钛合金钢板、护城河、命门、脊梁、尊严、沸腾、咆哮
- 口头禅/标志性表达：
  - "是的"——用于确认反常识事实后强化冲击
  - "对你没听错"——制造反差惊讶
  - "兄弟们"——拉近距离、制造共鸣
  - "大错特错"——否定常识判断后反转
  - "说白了"——将复杂逻辑翻译成人话
- 专业术语偏好：产业链、供应链、产能、装机量、市场份额、本土化配套率、技术授权、固态电池、钠离子电池
- 禁用风格：
  - 不用emoji（与硬核严肃调性冲突）
  - 不用网络流行语/梗（与深度叙事调性冲突）
  - 不用"点赞关注"类CTA（与自信从容的品牌调性冲突）
  - 不用学术腔/公文腔（与口语化热血风格冲突）

### 篇幅与节奏
- 默认篇幅：长文1500-2000字（热点快评可短至600字）
- 段落长度偏好：中等偏长段落4-8句，连贯叙事流，不碎片化

## 结构模板

### 模板一：逆袭叙事弧（使用频率~87%）

```
1. 钩子引入：用一个戏剧性场景/反差事件开场（韩国综艺在南极破防/美国加税小厂硬刚/县城缝纫机厂造机器人）
2. 逆境铺垫：交代主角的弱势处境（被请出会场/濒临倒闭/被讥讽为杂牌/年轻人不愿进场）
3. 反击展开：详细铺陈逆袭路径（技术突破/产业链布局/政策梭哈/成本碾压）
4. 逻辑论证：密集数据+案例验证（市场份额/成本对比/专利结果/FDA认证）
5. 情绪升华：从具体事件升维到民族/时代/尊严层面
6. 金句收刀：一句铿锵有力的断言结尾
```

### 模板二：制度反思型（使用频率~13%）

```
1. 现象引入：一个正在发生的切身变化（进口药越来越难配到）
2. 多方立场呈现：政策方/企业方/患者方的不同视角
3. 不可能三角揭示：便宜、优质、人人有份无法兼得
4. 警示收尾：不给简单答案，留下思考空间
```

### 示例 1
**标题**：三拳打碎关税梦，一个内蒙猪饲料厂如何反击美国

当美国掀了桌子，越南和澳大利亚等国研究怎么投降的时候，一家内蒙古的小厂竟然直接硬刚关税，你家涨价我说了算。是的，他们直接掏出了祖传的猪饲料。对你没听错，就是喂猪的金霉素。泾河的猪饲料学名金霉素，不仅能防猪瘟，还能让猪猪少吃饭，多长肉。美国畜牧业每年狂吞5万吨，全球90%产能在中国手里，美国本土连个像样的工厂都没有。面对关税大棒，金河生物抡出了三记铁拳。从草原到白宫，从饲料到核武，中国制造的密码从来只有一条，把饭碗端在自己手里，把落后的帽子狠狠扔向太平洋的另一边。

### 示例 2
**标题**：张雪带中国机车登顶，这一战重庆摩托硬刚全世界

说实话，此时此刻我的热血还在沸腾。中国摩托车品牌张雪机车在SSP组别中连夺两个回合冠军，实现两连冠。四秒兄弟们，在时速近300公里的赛场上，这简直就是跨代级的凌辱，是让雅马哈、杜卡迪这些老牌贵族感到绝望的暴力拆解。为什么说这是产业链的胜利？兄弟们，比赛不只是看车手那几分钟，看的是背后的迭代速度。在重庆，依靠半径50公里的供应链圈，几天内就能出样件，一个月就能完成从末尾到冠军的神级进化。当他在直播间激动落泪时，他哭的不只是那个19岁在雨中追梦的自己，更是哭那段被国外技术封锁、被讥讽为杂牌的屈辱岁月终于在这一刻彻底终结了。以后谁再敢说中国机车是地平线，请把张雪夺冠的视频甩在他脸上。

### 示例 3
**标题**：昔日市场换技术，今朝全球跳动中国心

作为全美最顶尖的科技先锋杂志，连线在过去40年的历史里，几乎从来没有给一个国家搞过特辑。但就在最近，十几名资深记者像特种部队一样飞抵上海、杭州、北京，他们记录下了一个让西方工业集体失眠的真相。宁德时代一家就以464.7吉瓦时的装机量占据了近四成的市场份额，是韩日上榜巨头总和的两倍多。这是一种令人窒息的统治力。傲慢如底特律，在当今的中国能源科技面前，也不得不低下头，交出一份价值百亿的技术投名状。曾经我们是用市场换技术，现在世界在用主权换技术。这跳动着、澎湃着的红色心脏，正紧紧握在中国人的手中。真正的护城河，从来不是你拥有什么，而是别人想拿也拿不走什么。

## 使用说明

### 擅长场景
- 中国产业/企业逆袭深度叙事（制造业、新能源、科技、医药）
- 大国博弈背景下的产业分析文
- 热点事件的热血解读（关税战、技术封锁、产业政策）
- 以小见大的产业故事（小厂/小城/小人物的逆袭）

### 失真场景
- 纯情感类软文（无产业逻辑支撑的情绪文）
- 轻松搞笑/段子类内容
- 纯学术分析/研报式内容（缺少叙事弧线）
- 生活方式/美食/旅行类内容

### 建议输入格式
- 最佳：给一个具体产业/企业话题+逆袭或博弈的切入角度（如"写一篇关于XX企业如何打破国外垄断的深度叙事"）
- 可用：只给一个产业关键词（如"半导体""光伏"）
- 避免：完全不给方向，或要求写非产业类内容
