# Account Abstracter

> **给我一个账号，还你一个灵魂。**

从任何新媒体账号的公开作品中逆向工程创作者的写作 DNA，封装成一份 `.skill` 文件，让任何 Agent 都能复刻目标账号的文风、节奏和叙事逻辑。

## 这是什么

Account Abstracter 是一套**四层逆向工程体系**，用于将新媒体账号的创作风格系统化提取并封装为可复用的 Skill 文件：

```
账号名 + 作品文本
        ↓
  ┌─────────────┐    ┌─────────────────┐
  │  Layer 1    │    │   Layer 2       │
  │  检索层     │    │   文本分析层    │
  │  平台搜索   │    │   作品解剖      │
  └──────┬──────┘    └────────┬────────┘
         │           [身份确认]│
         └────────┬───────────┘
                  ↓
          整合数据池（文本优先，检索补充）
                  ↓
          ┌───────────────┐
          │   Layer 3     │
          │   分析层      │
          │   画像合成    │
          └───────┬───────┘
                  ↓
          [用户确认画像]
                  ↓
          ┌───────────────┐
          │   Layer 4     │
          │   Skill封装层 │
          └───────┬───────┘
                  ↓
          [回测验证] → 通过 → soul/<账号名>.skill
```

## 核心特性

- **🔍 检索层**：自动搜索公众号/微博/知乎/B站等8大平台，确认账号身份
- **🧬 文本解剖**：11个维度深度分析——标题规律、开头结尾模式、段落结构、高频词汇、数据引用习惯、情感弧线、排版风格……
- **🎯 画像合成**：文本分析优先、检索信息补充，矛盾标记让用户裁决，每条结论附置信度
- **📦 Skill 封装**：一键输出 `.skill` 文件，包含角色设定、写作规则、结构模板、词汇库、金句模式、Few-shot 示例
- **✅ 回测验证**：生成内容与原作4维对比（文风/结构/词汇/情感），相似度不达标就回炉

## 目录结构

```
account-abstracter/
├── SKILL.md                          # Skill 定义文件（完整工作流）
├── README.md                         # 你正在看的
├── references/                       # 参考文档
│   ├── analysis-dimensions.md        # 分析维度详解
│   ├── output-schemas.md             # 各层输出 Schema
│   ├── platform-search-strategy.md   # 平台搜索策略
│   └── skill-template.md             # Skill 封装模板
├── scripts/
│   └── validate_skill.py             # Skill 文件验证脚本
└── soul/                             # 输出目录
    └── 兽楼处.skill.md               # 示例：兽楼处风格 Skill
```

## 快速开始

1. 在 WorkBuddy 中加载此 Skill
2. 输入账号名称和/或作品文本路径
3. 确认账号身份 → 确认画像 → 自动封装
4. 在 `soul/` 目录下获取生成的 `.skill` 文件

## 兼容平台

- Claude
- Open Claw
- WorkBuddy
- 任何支持 Skill 注入的 Agent 平台

## 示例输出

已在 `soul/` 目录下提供「兽楼处」的风格 Skill 示例，回测综合相似度 **0.90**。

所有生成的 Skill 文件均包含伦理声明：基于公开作品分析生成，仅供学习研究参考，不代表原作者立场，不得用于冒充原作者发布内容。
