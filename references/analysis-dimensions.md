# 分析维度详解

本文档详细说明 Layer 2 文本分析层和 Layer 3 分析层中各维度的分析方法和判断标准。

---

## 基础维度

### 1. 标题规律

**分析目标**：提取账号在标题创作上的固定模式

**分析项**：
- 字数分布：平均字数、字数范围、最常见字数
- 句式类型：陈述句 / 疑问句 / 感叹句 / 祈使句 / 数字开头
- 情绪词使用：正面 / 负面 / 中性，高频情绪词列表
- 标题结构：是否有固定前缀/后缀、是否使用分隔符（|、-、/）、是否使用数字序号
- 标题钩子类型：悬念型 / 利益型 / 痛点型 / 故事型 / 对比型 / 争议型

**判断标准示例**：
| 特征 | 判断 |
|------|------|
| 超过60%标题使用疑问句 | 该账号偏好疑问式标题 |
| 标题常含具体数字（如"3个方法"） | 偏好数字钩子 |
| 标题平均>20字 | 偏好长标题 |

### 2. 开头/结尾模式

**分析目标**：识别内容首尾的固定套路

**开头钩子类型**：
- 场景引入：描述一个具体场景/故事
- 问题引入：直接抛出问题
- 数据引入：用数据/统计开头
- 观点引入：直接亮明观点
- 痛点引入：描述读者痛点
- 引用引入：引用名言/他人观点

**结尾模式**：
- 行动号召（CTA）：引导点赞/关注/评论
- 总结回顾：要点重新罗列
- 升华拔高：从具体到抽象
- 开放式：留给读者思考
- 金句收尾：以金句/感悟结束

**分析项**：
- 各类开头钩子的使用频率和分布
- 结尾是否固定使用某种模式
- 首尾是否存在呼应关系

### 3. 段落结构

**分析目标**：识别内容组织方式

**分析项**：
- 平均段落长度（字数）
- 长短句比例
- 分段逻辑：按时间 / 按论点 / 按步骤 / 按对比
- 是否使用小标题分隔
- 是否使用编号/列表
- 段落间过渡方式

### 4. 高频词汇与表达

**分析目标**：提取账号的标志性用词

**分析项**：
- Top 50 高频词（去除停用词后）
- 标志性表达/口头禅
- 专业术语使用频率
- 中英文混用习惯
- 特定领域黑话/行话

### 5. 数字/数据引用习惯

**分析目标**：识别数据使用模式

**分析项**：
- 数据引用密度（每千字数据引用次数）
- 数据来源类型：研究报告 / 官方统计 / 个人经验 / 不注明来源
- 数据呈现方式：精确数字 / 模糊范围 / 对比数据
- 是否有"编造感"数据的倾向

### 6. 案例/故事使用频率

**分析目标**：识别论证支撑方式

**分析项**：
- 案例使用密度
- 案例类型：名人案例 / 自身经历 / 读者案例 / 虚构案例
- 案例长度：一句话带过 / 一段详述 / 贯穿全文
- 案例与论点的衔接方式

## 增强维度

### 7. 内容主题聚类

**分析目标**：识别创作者的核心话题域

**分析方法**：
1. 提取每篇作品的核心主题词
2. 按主题词相似度进行聚类
3. 识别常驻话题（出现频率>30%）和偶发话题
4. 判断话题域的宽度：垂直型（1-2个主题） / 宽泛型（5+主题）

**输出格式**：
```
核心主题域：[科技创业 / 职场成长 / 生活方式]
常驻话题：[创业方法论(60%), 认知升级(45%), 读书笔记(35%)]
偶发话题：[旅行(10%), 美食(5%)]
话题域宽度：中等垂直
```

### 8. 互动/CTA模式

**分析目标**：识别引导读者互动的套路

**CTA类型识别**：
- 直接提问型："你怎么看？""你遇到过吗？"
- 行动引导型："点赞收藏""关注不迷路"
- 评论诱导型："评论区告诉我""来评论区聊聊"
- 转发驱动型："转发给需要的人""@你的朋友"
- 情感共鸣型："如果也有同感，点个赞"

**分析项**：
- CTA出现位置：文末 / 文中穿插 / 标题
- CTA使用频率
- 主要CTA类型偏好
- CTA措辞的个性化特征

### 9. 发布节奏与篇幅规律

**分析目标**：识别内容产出的节奏和体量模式

**分析项**：
- 典型篇幅范围（字数区间）
- 平均篇幅
- 篇幅分布：均匀型 / 两极分化（长短交替）
- 更新频率推断（如有发布时间信息）

**篇幅分类参考**：
| 类型 | 字数范围 |
|------|----------|
| 短文/动态 | <500字 |
| 中篇 | 500-1500字 |
| 长文 | 1500-3000字 |
| 深度长文 | >3000字 |

### 10. 情感弧线

**分析目标**：识别单篇内容的情感走势模式

**常见情感弧线类型**：
- **递进→爆发→收束**：层层递进，高潮后收尾（最常见）
- **平铺直叙**：情感平稳，信息密集
- **反转式**：先铺垫预期，然后反转
- **共鸣升华**：从具体到抽象，从小情感到大感悟
- **痛点→解药**：先制造焦虑，再给解决方案
- **叙事弧**：起承转合完整故事线

**分析方法**：
1. 将每篇内容按段落/部分切分
2. 对每部分做情感倾向标注（积极/消极/中性）
3. 绘制情感走势曲线
4. 归类到上述弧线类型

### 11. 视觉排版习惯

**分析目标**：识别文本的视觉呈现特征

**分析项**：
- 分段密度：段落平均行数
- Emoji使用：频率、类型偏好、位置（标题/正文/结尾）
- 分隔符使用：是否使用 ---、***、=== 等
- 列表使用：有序/无序、嵌套层级
- 引用格式：是否频繁使用引用块
- 强调方式：加粗 / 斜体 / 颜色标注
- 空行使用：段落间空行数量

## 置信度标签标准

| 置信度 | 判断标准 |
|--------|----------|
| 高 | 5+篇作品，维度特征一致性强（>70%的作品表现一致） |
| 中 | 3-4篇作品，或5+篇但特征一致性一般（40-70%） |
| 低 | 1-2篇作品，或3+篇但特征一致性差（<40%） |

特征一致性 = 表现出该维度特征的作品数 / 总作品数
