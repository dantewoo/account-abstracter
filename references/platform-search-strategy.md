# 平台搜索策略映射

## 各平台检索策略

### 微信公众号

| 项目 | 策略 |
|------|------|
| 搜索入口 | 搜狗微信搜索 `weixin.sogou.com` |
| 搜索语法 | `公众号名称 site:mp.weixin.qq.com` 或直接搜狗微信搜索 |
| 登录要求 | 不需要 |
| 反爬风险 | 低，但频繁搜索可能触发验证码 |
| 可获取信息 | 账号名称、简介、近期文章标题和摘要、认证信息 |
| 注意事项 | 站内搜索不可用，必须走搜狗；部分历史文章可能被删除 |

### 微博

| 项目 | 策略 |
|------|------|
| 搜索入口 | 站内搜索 + 百度 `site:weibo.com` |
| 搜索语法 | 站内直接搜用户名；百度用 `用户名 site:weibo.com` |
| 登录要求 | 未登录可看部分，登录后信息更全 |
| 反爬风险 | 中等，频繁请求可能触发风控 |
| 可获取信息 | 昵称、简介、粉丝数、关注数、近期微博、认证信息 |
| 注意事项 | 优先走站内，补充用百度；注意区分个人号和机构号 |

## 通用搜索技巧

1. **精确匹配**：用双引号包裹账号名进行精确搜索 `"账号名"`
2. **多平台交叉验证**：同一创作者可能在多个平台有账号，交叉比对可提高准确性
3. **搜索结果去重**：同一账号信息可能出现在多个搜索结果中，去重后整合
4. **时效性过滤**：优先获取最近3个月的信息，历史信息作为补充

## 失败兜底方案

| 情况 | 处理策略 |
|------|----------|
| 搜不到账号 | 提示用户检查名称是否正确，或跳过检索层仅走 Layer 2 |
| 搜到但信息极少 | 降低检索数据权重，Layer 3 标注"检索数据不足" |
| 平台需要登录但未登录 | 提示用户登录后重试，或跳过该平台 |
| 搜索结果全是仿号/重名 | 展示前3个结果让用户选择，或跳过 |
| 频繁触发反爬/验证码 | 降低请求频率，换用搜索引擎间接获取 |
| 网络超时 | 重试1次，仍失败则跳过该平台 |
